# Netflix Content Analytics Dashboard

## Project Overview
This project focuses on analyzing Netflix content using Data Analytics, Business Intelligence, and Data Storytelling techniques. The project includes data cleaning, exploratory data analysis, dashboard creation, and statistical validation.

## Objectives
- Analyze Netflix content trends
- Identify popular genres and ratings
- Compare Movies and TV Shows
- Build an interactive dashboard
- Perform hypothesis testing

## Tools & Technologies
- Python
- Pandas
- Tableau
- Canva
- SciPy

## Key Insights
- Netflix content increased rapidly after 2015
- Movies dominate the platform
- Drama and Documentary are highly popular genres
- USA and India contribute the most content
- TV-MA is the most common rating

## Dashboard Features
- KPI cards
- Genre analysis
- Country-wise analysis
- Ratings distribution
- Interactive filters
- Trend analysis

## Statistical Validation
An Independent T-Test was performed to compare Movie and TV Show durations. The test confirmed a statistically significant difference between them.

This project demonstrates how Business Intelligence and Data Storytelling can transform raw streaming data into meaningful business insights.
