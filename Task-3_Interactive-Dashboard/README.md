# Netflix Content Analysis Dashboard

## Overview
This project focuses on performing a deep-dive analysis of Netflix Movies and TV Shows data using Python and Tableau. The objective was to uncover meaningful insights, define business KPIs, and build an interactive dashboard for business intelligence reporting.

The project includes data cleaning, exploratory data analysis (EDA), KPI generation, trend analysis, and dashboard visualization using a Netflix-themed design.

---

## Objectives
- Analyze Netflix content trends and patterns
- Identify top-performing genres and ratings
- Understand country-wise distribution of content
- Compare Movies vs TV Shows
- Build an interactive business intelligence dashboard

---

## Tools & Technologies
- Python
- Pandas
- Matplotlib

- VS Code

## Dataset
Dataset Used:
- Netflix Movies and TV Shows Dataset

Main Columns:
- Title
- Type
- Country
- Rating
- Release Year
- Date Added
- Genre (Listed In)
- Duration

## Project Workflow

### 1. Data Cleaning & Preparation
- Removed duplicate records
- Handled missing values
- Converted date columns
- Extracted duration information
- Standardized data types

### 2. Exploratory Data Analysis (EDA)
- Distribution of Movies vs TV Shows
- Country-wise content analysis
- Genre analysis
- Rating distribution analysis
- Year-wise growth trends
- Correlation and trend analysis

### 3. Business Intelligence Dashboard
Created an interactive Netflix-themed dashboard in Tableau with:
- KPI cards
- Genre analysis
- Rating analysis
- Country-wise visualization
- Year-wise trends
- Interactive filters

---

## Key Insights
- Movies dominate Netflix content compared to TV Shows
- TV-MA is the most common content rating
- United States and India contribute the highest content
- Content additions increased rapidly after 2015
- Documentaries and International Dramas are among the most popular genres
