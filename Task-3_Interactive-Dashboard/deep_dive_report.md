# Deep-Dive Analysis Report — Netflix Content Dashboard

## Project Title
Netflix Content Analysis & Interactive Dashboard

---

# 1. Introduction

This project focuses on analyzing Netflix Movies and TV Shows data to discover trends, patterns, and business insights. The analysis was performed using Python for data preprocessing and Tableau for interactive dashboard development.

The main objective was to create a professional business intelligence dashboard capable of providing insights into Netflix content distribution, ratings, genres, and country-wise trends.

---

# 2. Objectives

- Perform deep-dive analysis on Netflix dataset
- Define and monitor important KPIs
- Identify content growth trends
- Analyze content distribution by country and genre
- Build an interactive Tableau dashboard

---

# 3. Tools Used

| Tool | Purpose |
|---|---|
| Python | Data cleaning and preprocessing |
| Pandas | Data manipulation |
| Matplotlib | EDA visualizations |
| Tableau Public | Interactive dashboard |
| VS Code | Development environment |

---

# 4. Dataset Information

Dataset: Netflix Movies and TV Shows Dataset

Total Records: 6,233+

Important Columns:
- show_id
- type
- title
- country
- rating
- duration
- release_year
- listed_in

---

# 5. Data Cleaning & Preparation

The following preprocessing steps were performed:

- Removed duplicate rows
- Handled missing values
- Converted date columns into datetime format
- Extracted numerical duration values
- Created additional analysis columns

---

# 6. Key Performance Indicators (KPIs)

The following KPIs were defined:

| KPI | Description |
|---|---|
| Total Titles | Total number of Netflix titles |
| Total Countries | Number of countries producing content |
| Movie vs TV Show Ratio | Comparison of content types |
| Top Genre | Most common content genre |

---

# 7. Deep-Dive Analysis

## A. Country-wise Content Analysis
A geographical analysis was performed to identify countries contributing the highest number of Netflix titles.

### Findings:
- United States contributed the highest content volume
- India ranked among the top content-producing countries
- Multiple countries showed moderate content growth

---

## B. Genre Analysis
The top 10 genres were analyzed using bar charts.

### Findings:
- Documentaries were highly popular
- International Dramas showed strong presence
- Stand-Up Comedy gained significant representation

---

## C. Rating Analysis
Content ratings were analyzed to understand audience targeting.

### Findings:
- TV-MA was the dominant rating
- TV-14 and TV-PG also had high counts
- Kids content represented a smaller share

---

## D. Year-wise Trend Analysis
Content addition trends were analyzed across years.

### Findings:
- Rapid increase in Netflix content after 2015
- Significant growth observed between 2017–2019
- Content expansion strategy became more aggressive over time

---

## E. Movies vs TV Shows Analysis
A comparative analysis between Movies and TV Shows was conducted.

### Findings:
- Movies formed the majority of Netflix content
- TV Shows occupied a smaller but growing share

---

# 8. Dashboard Development

An interactive Tableau dashboard was created with:
- KPI cards
- Country map visualization
- Genre analysis
- Rating distribution
- Year-wise trend analysis
- Interactive filters

The dashboard followed a Netflix-inspired red and black theme for visual consistency.

---

# 9. Business Insights

- Netflix primarily focuses on Movies over TV Shows
- Mature audience content dominates the platform
- International content diversity is increasing
- Content production accelerated significantly after 2015
