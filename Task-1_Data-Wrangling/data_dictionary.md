# Netflix Data Dictionary

| Column Name   | Description                          | Data Type |
|--------------|--------------------------------------|----------|
| show_id      | Unique ID of show                    | string   |
| type         | Movie or TV Show                     | string   |
| title        | Name of content                      | string   |
| director     | Director name                        | string   |
| cast         | Actors involved                      | string   |
| country      | Production country                   | string   |
| date_added   | Date added to Netflix                | date     |
| release_year | Release year                         | int      |
| rating       | Content rating (TV-MA, PG, etc.)     | string   |
| duration     | Duration in minutes/seasons          | string   |
| listed_in    | Genre/category                       | string   |
| description  | Short summary of content             | string   |
