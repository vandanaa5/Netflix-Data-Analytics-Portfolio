# Netflix Data Analytics Portfolio

## Overview
This portfolio showcases an end-to-end Data Analytics project using the Netflix dataset. The project covers Data Wrangling, Exploratory Data Analysis (EDA), Business Intelligence, Interactive Dashboarding, Data Storytelling, and Statistical Validation.

---

## Tasks Completed

### Task 1 — Data Wrangling
- Cleaned and transformed raw Netflix dataset
- Handled missing values and duplicates
- Created data dictionary and quality report

### Task 2 — Exploratory Data Analysis & Business Intelligence
- Performed descriptive and multivariate analysis
- Identified trends in genres, ratings, and content growth
- Generated business insights using Python visualizations

### Task 3 — Deep-Dive Dashboarding
- Built an interactive Tableau dashboard
- Created KPI cards and business-focused visualizations
- Implemented filters and Netflix-themed dashboard design

### Task 4 — Data Storytelling & Statistical Validation
- Developed storytelling presentation in Canva
- Performed hypothesis testing using Python and SciPy
- Derived strategic business recommendations

## Key Insights
- Netflix content increased rapidly after 2015
- Movies dominate over TV Shows
- Drama and Documentary genres are highly popular
- USA and India contribute the highest content volume
- Statistical testing confirmed significant duration differences between Movies and TV Shows
